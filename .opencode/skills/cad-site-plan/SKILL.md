# CAD Site Plan

Generate civil engineering grade site plan drawings (PNG/PDF) from lot geometry, setbacks, and building specifications.

## When to Use

Use this skill when a user provides:

- A property address
- An APN (Assessor's Parcel Number)
- Lot dimensions

and needs a CAD-style site plan image for:

- Reports
- Investor packages
- Preliminary review
